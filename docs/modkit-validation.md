# modkit validation errors

Every error that modkit's validation (`python -m modkit build .`) reports on a fresh `pd2_merge.py`, with its cause and status. `modkit build` prints only the first 15 to the console. `out/validation.md` groups them and shows 3 examples per kind. This list has every row.

**Rule:** a PR that fixes any of these is not merged until an in-game test shows the fix works and breaks nothing else (Hell, a level 90+ character). Tool tests, the diff gate and CI don't show what D2R does with the data.

Counts, generated 2026-11-04 (main plus [#172](https://github.com/synpoox/pd2-resurrected/pull/172)):

|---|---|
| On `main` | 144 |
| Fixed in #172 (in-game test pending) | 57 |
| Open ([#171](https://github.com/synpoox/pd2-resurrected/issues/171)) | 87 |

Cause words:
- **keeps PD2's behaviour:** the fix gives the same result in the game as live PD2, because 1.13c found no row for the value either.
- **pd2-origin fix:** a bug that shows on live PD2, fixed here and listed in [pd2-origin-bugs.md](pd2-origin-bugs.md).
- **probably:** not yet checked against 1.13c's code for that column.
