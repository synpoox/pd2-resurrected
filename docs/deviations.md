# Deviation list

Every deviation from the PD2 baseline, and why (see [GLOSSARY.md](../GLOSSARY.md)). D2R-only content is not a
deviation. PD2's own bugs that we fixed are listed in [pd2-origin-bugs.md](pd2-origin-bugs.md).

Each row has a status:

- **cut**: left out on purpose.
- **not yet**: still to build; **Work item** names the item that builds it.
- **approximated**: in the port, but it works or looks different from PD2.

Contents: [Features and data](#features-and-data), [Engine rules](#engine-rules), [Data rows](#data-rows),
[Gate patterns](#gate-patterns) (for `tools/pd2_diff.py`).

## Gate patterns

`tools/pd2_diff.py` reads the **Status** of every row above, and here the **Gate** patterns each row covers: each
backticked `table.row.column` pattern (fnmatch, any case; `*` also spans dots) covers the table-diff gate's deviations
it matches. **Deviation** must name a row above, word for word; the gate fails otherwise. The gate compares the excel
tables only; rows without a pattern (strings, engine rules, features) are checked by hand or by the game check. A work
item that merges a table removes or narrows its row here and above; the gate fails while a whole-table pattern
(`table.*`) still covers a merged table.

The gate's report counts two things. **Entries** are the rows above, by status: "not yet" entries are the work still to
do. **Table cells** are every cell difference those rows cover. One row can cover a whole table (the sounds table alone
is thousands of cells), so the cell count shows breadth, not work left.
