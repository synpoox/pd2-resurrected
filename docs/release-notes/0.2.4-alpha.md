Patch notes for 0.2.4-alpha. This build runs on Diablo II: Resurrected 3.4 and 3.3.

## Fixes

- Throwing weapons, throwing potions, arrows and bolts no longer split with Ctrl+click, as in PD2.
- The launcher now receives each release, and accepts both the 3.3 and 3.4 Battle.net builds of Diablo II: Resurrected.
