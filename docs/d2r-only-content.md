# D2R-only content ledger

D2R content PD2 does not have (Warlock excepted) is **on** by default. An item is turned off only by an
approval recorded here; turning off keeps the row in place for ID stability (`spawnable 0`, out of treasure
classes, recipes disabled, areas unlinked). Large items (Terror Zones, RotW areas) get their own decision ticket
first.
